# Carte de la grammaire

Carte mentale interactive pour réviser la grammaire du français au CRPE, d'après le guide Eduscol *La grammaire du français. Terminologie grammaticale* (niveaux I et II). Chaque notion a sa fiche : définition, exemples, manière de la reconnaître, natures ou fonctions possibles (d'après les tableaux de l'annexe), volet « Approfondir » pour le niveau II et renvoi aux pages du guide.

La page comprend aussi un mode révision, les confusions classiques et un entraînement par QCM.

## Vérifier le contenu

```bash
node --test tests/
```

Le vérificateur contrôle les identifiants, les pages, les liens nature ↔ fonction, la couverture du sommaire, la terminologie, les confusions et les questions.
